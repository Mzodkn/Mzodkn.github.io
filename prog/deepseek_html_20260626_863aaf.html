Components of the Computer System

🖥️ Hardware

The physical equipment that make up a computer system. Major hardware components include:

  • Central Processing Unit (CPU)
  • Main Memory (MM) — also called Random Access Memory (RAM)
  • Input / Output devices
  • Secondary storage

📦 Software

Programs written to perform specific tasks. All software is written in programming languages.

System Programs Application Programs
  • System programs — control the computer. The operating system loads first; without it, the computer is useless.
  • Application programs — perform specific tasks (word processors, spreadsheets, games). The OS runs application programs.

Programming Languages

A collection of instructions, symbols and rules used to write a program (code) to perform a specific job.

1GL · Machine

Lowest level

The language used to program first-generation computers. Instructions are made of binary numbers (0s and 1s), corresponding to off/on states of electrical switches.

Suitable for machines, very difficult for humans.

2GL · Assembly

Low-level

Allows programmers to use abbreviations or easily remembered words instead of numbers. An assembler translates assembly into machine language.

LOAD X
MULT y
STOR z

3GL · High-Level

Closer to natural language

Refinement of 2GL. Uses familiar notation rather than numbers or abbreviations. Most high-level languages are not machine dependent.

Translators: Compiler or Interpreter.

Each language follows its own syntactic and semantic rules.

Introduction to C++ Concepts

Computer Programs

Also known as "Code" — a collection of instructions that can be executed to perform a specific task.

Program / Code Components

  • Constants — fixed values/data in the program body. const cannot be reassigned.
  • Variables — changeable values/data in the program.
  • Methods — procedures/functions that perform certain tasks.

Program Structure Example

// my first program in C++
#include <iostream.h>

int main ()
{
  cout << "Hello World !";

}

C++ Language Components

A C++ program consists of statements; any statement consists of words; any word composes of a set of letters:

  • Numbers: 0, 1, ..., 9
  • Alphabet: A–Z, a–z
  • Symbols, special characters, and mathematical operators: ( ) { } . ; / + - and others

Words (names) in C++ can be built of alphabet, numbers, and underscore (_).

Rules for C++ Names

  1. A name must start with a letter or underscore.
  2. A name cannot start with a number.
  3. A name can only contain alpha-numeric characters and underscores (A–z, 0–9, _).
✅ Valid: count, stud_name, age1, _pl ❌ Invalid: cnt*, stud name, 1age

Reserved words (keywords) cannot be used as user-defined names: class, main, public, void, static, etc.

Comments in C++

A comment in C++ code is a line that is not read/executed as part of the program. Its only purpose is to be read by someone looking at the code.

  • Let others understand what you are doing
  • Remind yourself of what you did — most programmers have experienced coming back to their own work a year or two later and having to re-figure out what they did.
/*
Here is a block comment.
*/

/* Here is a single-line comment. */

cout << "Hello"; // An end-of-line comment.

#include <iostream.h>

  • Preprocessor directive — #include <iostream> includes the input/output stream header.

Control Statements

Sequence Statements

Statements can be executed in sequence — one right after the other, with no deviation from the specified sequence.

Selection Statements

A selection statement chooses which statement to execute based on whether the expression is true or false.

if if...else Nested if switch
if Statement ▾

Syntax:

if ( logicalExpression ) statement;

Example:

if (x < 5)
  cout << "low value for x";

Also known as single-selection statement. If the expression is true, the statement is executed; if false, nothing happens.

if...else Statement ▾

Syntax:

if (condition)
  statement1;
else
  statement2;

Example:

if (x < 5)
  cout << "low x";
else
  cout << "high x";

Also known as double-selection statement.

Conditional Operator (?:) — closely related to if...else.

grade >= 50 ? cout << "Passed" : cout << "Failed";
Compound Statements ▾

When multiple statements need to be controlled by the if, group them in curly brackets { }.

if (x < 5)
{
  x = x + 10;
  cout << x;
}
Nested if & Dangling else ▾

A statement after if (...) can be any kind of statement — including another if.

Dangling else rule: An else goes with the closest unmatched if.

if (x > 5)
  if (y > 5)
    cout << "x and y are > 5";
  else
    cout << "y is <= 5";
else
  cout << "x is <= 5";

Use nested statements to force an else to go with a previous if.

switch Statement ▾

C++ provides the switch statement for multi-way branching.

switch (choice) {
  case 1 : do_option_one(); break;
  case 2 :
  case 3 : do_2_3_a(); do_2_3_b(); break;
  default : do_something_else();
}
  • Switch expression — cannot be floating point; usually int or char.
  • case identifiers must be constants.
  • break causes control to shift to the first statement after the switch.
  • default executes if the value is NOT found among switch labels.

Repetition Statements

Also called looping statements — statements can be repeated. The number of repetitions depends on when the expression turns false.

while do...while for
while Loop ▾

Syntax:

while (Expression) statement;

Example:

int i;
i = 0;
while (i <= 20) {
  cout << i << " ";
  i = i + 5;
}

Requires: control variable, initial value, loop condition, increment/decrement.

do...while Loop ▾

Syntax:

do
  statement;
while (Expression);

Difference from while: do...while executes the statement at least once.

i = 11;
do {
  cout << i << " ";
  i = i + 5;
} while (i <= 10);
for Loop ▾

Syntax:

for (initial statement; loop condition; update statement)
  statement;

Execution flow:

  1. The initial statement executes.
  2. The loop condition is evaluated. If true:
    • Execute the for loop statement.
    • Execute the update statement.
  3. Repeat Step 2 until the loop condition evaluates to false.
// Infinite for loop — prints "Hello" continuously
for (;;) cout << "Hello" << endl;

Functions (Modules)

Functions are like building blocks. They let you divide complicated programs into manageable pieces.

  • While working on one function, you can focus on just that part and construct, debug, and perfect it.
  • Different people can work on different functions simultaneously.
  • If a function is needed in more than one place, you can write it once and use it many times.
  • Using functions greatly enhances program readability.

In C++, functions can be predefined or user-defined.

User-Defined Functions

Two categories:

  • Value-returning functions — have a return type and return a value using return.
  • Void functions — do not have a return type; do not return a value.
Value-Returning Functions ▾

Syntax:

functionType functionName( formal parameter list )
{
  statements
}

Example:

double larger(double x, double y)
{
  double max;
  if (x >= y) max = x;
  else max = y;
  return max;
}

The return statement passes a value outside the function.

Void Functions ▾

Syntax:

void functionName( formal parameter list )
{
  statements
}

Example:

void larger(double x, double y)
{
  double max;
  if (x >= y) max = x;
  else max = y;
  cout << max << endl;
}
Function Overloading ▾

Several functions can have the same name. This is called function overloading.

Two functions have different formal parameter lists if:

  • A different number of formal parameters, or
  • If the number is the same, then the data type of the formal parameters (in order) must differ in at least one position.
void functionOverload();
void functionOverload(int x);
void functionOverload(int x, double y);
void functionOverload(double y, int x);
int functionOverload(char ch, int x, double y);
int functionOverload(char ch, int x, string name);
Function Prototypes ▾

A function prototype is the function heading without the body. It appears before any function definition (including main).

Syntax:

functionType functionName(formal parameter list);

Example:

double larger(double x, double y);
// or
double larger(double, double);

The function prototype ends with a semicolon.

Full Example: Function Prototypes & Definitions

#include <iostream>
using namespace std;

void func1();
void func2();

int main() {
  int num;
  cout << "Enter 1 or 2: ";
  cin >> num;
  if (num == 1) func1();
  else if (num == 2) func2();
  else cout << "Invalid input" << endl;
  return 0;
}

void func1() { cout << "Programming I." << endl; }
void func2() { cout << "Programming II." << endl; }
